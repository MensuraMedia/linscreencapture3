## 3. Bugs found and fixed

### 3.1 Installing over LinShot 1.4 left PrintScreen dead

**Symptom.** After installing and starting the agent, PrintScreen still ran the old
`…/linshot/build/linshot --capture` (now deleted) and the agent wrote no desktop binding and no autostart entry.

**Cause.** `Settings._load_legacy` copied two 1.4 flags into 3.x settings that mean something else:
`start_with_os` → `autostart` and `default_screenshot_app` → `register_hotkey`. LinShot 1.4 bound its key through its
own Cinnamon custom shortcut no matter what those flags said, and its defaults were `false`. So a typical 1.4 user,
whose PrintScreen worked, got `register_hotkey=false` and `autostart=false` on first start: no binding, no agent at
login. Only the first start migrates; after that `~/.config/linscreencapture/settings.conf` exists and wins, and the
autostart entry on disk wins over the setting (`autostart.sync`), so the damage persisted.

**Fix.** Neither flag is migrated any more; both keep the 3.x defaults (on). The key itself still migrates
(`shortcut_key` → `hotkey`), so a 1.4 user who chose "none" (`shortcut_key=0`) still has no hotkey.
`linscreencapture/model/settings.py`; test `tests/model/test_settings_schema.py::test_legacy_off_flags_do_not_disable_the_hotkey`.
Docs: `INSTALL.md` (Upgrading from 1.x), `docs/CAPTURE.md` §4 and `docs/PRINTSCREEN.md` (dead-key diagnosis).

**Repair on an affected machine.** Settings → System: switch *Register with the desktop* and *Run at startup* on.
(Or quit the agent, set `register_hotkey=true` and `autostart=true` in the settings file, start it again.)

### 3.2 The installed app ran the checkout's code when started inside the checkout

**Symptom.** `/usr/bin/linscreencapture --background` started from `~/projects/linscreencapture3` failed with
`FileNotFoundError: …/projects/linscreencapture3/linscreencapture/linscreencapture.gresource missing`.

**Cause.** `python3 -m` puts the current directory first on `sys.path`, ahead of the launcher's `PYTHONPATH`, so the
checkout's package shadowed the installed one. The same applied to the tray helper the agent spawns.

**Fix.** The launcher written by `install.sh` (and so the `.deb`) runs `python3 -P -m linscreencapture`, and the tray
helper is spawned with `-P` (`app/application.py`; it already gets the agent's package through `PYTHONPATH`).
`-P` needs Python 3.11, already the minimum. Development launches (`tools/launch.sh`, the checkout fallbacks in
`services/autostart.py` and `services/hotkey_registrar.py`) run the checkout by design and are unchanged.

### 3.3 A leftover LinShot process swallowed PrintScreen (machine state, no code change)

The same failure `HANDOFF.md` §6 records from 2026-10-16 was live again: a `linshot --capture` process held an
XGrabKey on Print. Ending it and uninstalling LinShot (§2) cleared it. `docs/CAPTURE.md` §4 step 4 already covers it.

## 4. The application icon: the LinShot ring in #ffa222

At the operator's request, the app icon is LinShot's mark (a ring and a centre dot) in the LinScreenCapture orange,
replacing the orange tile with the selection frame and pointer (in use 2026-10-17 to 10-28).

- **Geometry**, measured from LinShot's `linshot-256.png` and reproduced exactly on the 256 grid: ring outer radius
  102, inner radius 77 (a 25 px stroke on radius 89.5), dot radius 26, centred; transparent margin 26 px.
- **Colour:** flat `#ffa222`, no gradient or outline (LinShot's was flat `#e6e6e6`).
- **Files:** the master `data/icons/hicolor/scalable/apps/com.mensuramedia.LinScreenCapture.svg` and the eight renders
  `resources/icons/linscreencapture-{16,24,32,48,64,128,256,512}.png`, made with `rsvg-convert` (the command is in
  `docs/ICONOGRAPHY.md`).
- **Where it shows:** every place reads those files by the theme name or path, so nothing else had to change: the
  program menu (`.desktop` `Icon=`), the panel window list and Alt+Tab (the SVG bundled in the `.gresource`), the
  tray (`tray.py` `ICON_FILE`), Startup Applications (autostart `Icon=`).
- **Docs updated:** `docs/ICONOGRAPHY.md`, `docs/FEATURES.md`, `docs/PRINTSCREEN.md`, `README.md`, the `tray.py`
  docstring.
